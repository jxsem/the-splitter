Subscription.php : 34

Modelo de Suscripción

Actúa como el punto central conectando usuarios, servicios y miembros. Representa una suscripción a un servicio que puede ser compartida entre múltiples personas. Gestiona el precio total, la fecha de renovación y el período de pago.
