\n Model\n User\n

\n

Ubicación: app/Models/User.php

\n

Representa a un usuario autenticado en la aplicación. Cada usuario puede ser propietario de múltiples suscripciones compartidas que gestiona con otros miembros.

\n\n
\n

Propiedades Principales

\n
id int - Identificador único
\n
name string - Nombre del usuario
\n
email string - Email único (credencial)
\n
password string - Contraseña hasheada
\n
email_verified_at datetime|null - Verificación
\n
\n\n
\n

🔗 Relaciones

\n
\n subscriptions() - HasMany
\n Obtiene todas las suscripciones del usuario\n
\n

\n Model\n Service\n

\n

Ubicación: app/Models/Service.php

\n

Representa una plataforma o servicio de suscripción (Netflix, Spotify, etc.) que puede ser compartida entre múltiples usuarios.

\n\n
\n

Propiedades Principales

\n
id int - Identificador único
\n
name string - Nombre del servicio
\n
price float - Precio mensual
\n
\n\n
\n

🔗 Relaciones

\n
\n subscriptions() - HasMany
\n Suscripciones de este servicio\n
\n

\n Model\n Subscription\n

\n

Ubicación: app/Models/Subscription.php

\n

Actúa como el punto central conectando usuarios, servicios y miembros. Representa una suscripción compartida.

\n\n
\n

Propiedades Principales

\n
id int - Identificador único
\n
user_id int - Usuario propietario
\n
service_id int - Servicio suscrito
\n
price float - Precio total
\n
renewal_date date - Próxima renovación
\n
period string - Período (monthly, trimesterly, annually)
\n
\n\n
\n

🔗 Relaciones

\n
\n user() - BelongsTo
\n Usuario propietario de la suscripción\n
\n
\n service() - BelongsTo
\n Servicio de la suscripción\n
\n
\n members() - HasMany
\n Miembros que comparten la suscripción\n
\n

\n

Ubicación: app/Models/Member.php

\n

Representa a una persona que comparte una suscripción (familia, amigos del usuario propietario).

\n\n
\n

Propiedades Principales

\n
id int - Identificador único
\n
subscription_id int - Suscripción
\n
name string - Nombre del miembro
\n
\n\n
\n

🔗 Relaciones

\n
\n subscription() - BelongsTo
\n Suscripción a la que pertenece\n
